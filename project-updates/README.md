# Project updates

One folder per Monday–Sunday week, named `YYYY-Www_<monday>_to_<sunday>` (ISO week numbers).
Each folder holds:

- `WEEKLY-SUMMARY.md`: highlights for the week and links to each day
- `YYYY-MM-DD.md`: one file per day anyone worked, using [`TEMPLATE.md`](TEMPLATE.md)
- `assets/`: photos and files for that week, named `YYYY-MM-DD_description.ext`

How to add an update is in the [root README](../README.md#how-to-post-an-update).

## About the backfill (Sep 1 – Nov 11, 2026)

The updates up to Nov 11 were written on Nov 12 from the team's records: the Discord export, the
Google Drive export (each member's media folder), Gabriel's Claude chat summaries, Hope's work
summaries, Roberto's daily logs and semester work report, and the git history. Each daily file lists
its sources. Times are Gainesville local time (EDT until Oct 31, EST from Nov 1).

- Only work found in those records is reported. A day with no record has no file, even if people worked.
- Work that the records can't pin to a single day is listed under **Undated work** in that week's summary.
- Phone numbers, emails, addresses, passwords, order and card details and off-topic chat were left out.
